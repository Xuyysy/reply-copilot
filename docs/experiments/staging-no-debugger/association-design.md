# 点击到回复编辑器关联实验

目标：在不调用 AI 的阶段验证真实 X 回复编辑器的关联。捕获可信激活的原帖 ID、请求 ID、URL、原节点与点击前的弹窗/编辑器集合。只接受随后出现、获得焦点、属于唯一新回复模态框的空白编辑器；嵌套 dialog 按同一节点去重。正文只作上下文一致性的辅助检查；存在状态链接时必须匹配，缺少链接时依赖激活、基线差分、焦点和未被打断的生命周期共同支持关联。

这是一种 DOM 层关联证据，并非 X 提供的加密身份保证。旧弹窗、多编辑器、竞争点击、非预期导航、节点重建、已有草稿、超时或正文不一致均失败关闭。原帖卸载不丢弃捕获的身份，原节点被复用成其他帖子则拒绝。输入前重新检查同一编辑器节点与操作有效性。

备选方案：继续要求弹窗状态链接会稳定拒绝当前真实 X；仅按正文关联可能串帖，拒绝采用。访问 React 私有对象或伪造事件可信性不采用。

实施：先完成独立状态机和失败场景测试，再接入内容脚本、默认 association-only 构建，在真实 X 只验证匹配和浮窗且禁止生成。该阶段通过后再显式构建输入验收包；不改变正式构建或商店包。
