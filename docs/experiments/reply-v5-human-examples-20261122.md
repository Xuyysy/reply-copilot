# V5 human-reply examples: experimental source-only stage 1

Base: exact Staging V4 source 829b8596251d004126d4bc1a244925201f0cd3a1. No cloud settings or deployment in this PR. V4 remains default, opt-in STAGING_REPLY_PROMPT_VERSION=v5 is Staging-only and requires independently authorized release/config change. No runtime dependencies, database, external retrieval, extra model call, billing or Chrome changes.

## Provenance and limitations

- 53 synthetic illustrative scenarios, not human data, covering zh/en/ja/ko.
- 28 selected Chinese adjacent turns from CDial-GPT toy train subset (https://github.com/thu-coai/CDial-GPT/blob/master/data/toy_data.json), blob aeee83e2be5ae94de6e5b32287834de1776adf66. Removed token-separator whitespace. Public README states research-use restriction; owner reports obtaining permission on 2026-11-22; independent permission documentation is not held in repository. Do not infer permission for every upstream corpus.
- 15 English post/reply pairs from https://github.com/IDEA-NTHU-Taiwan/unintended-offense-tweets/blob/main/scored_replies/averaged_scores_with_context.csv, blob 4303b89c734c38549e25642c11003a188d872d11. Exact CSV record ordinal including header, not a user ID. First tranche used offensiveness <=22, confidence >=70; second editorial tranche uses <=35, confidence >=60 with per-record scores retained. These are screening thresholds, not proof of appropriateness; handles/URLs removed and whitespace/entity normalized. Dataset is sampled for offense research, NOT representative of contemporary X or a human preference benchmark. Owner-reported permission recorded; no usernames, conversation IDs or author IDs stored. These are editorial candidates, not independently human-reviewed or verified commercial rights.
- No live web scraping or user data retrieval by Worker. No claims of human review, measured lift or latency improvement.
- The model sees a maximum of two matched examples, <=1000 UTF-8 bytes for their serialized JSON, no provenance identifiers. Same language heuristic, no fallback random examples, conservative serious-topic/injection exclusion. Explicit language selection honored, no change to primary language policy. Latin and Han-only detection remains heuristic. No rule-based claim of guaranteed detection.
- Never copy examples into generated replies or treat example facts as facts about current user. Style instructions only. V4 unchanged when retrieval has no match.
- Future ingestion: use authorized source files, retain source record+version and permission evidence, remove identifying data, manually review relevance/appropriateness, separate evaluation from examples. Do not auto-promote raw datasets or claim thousand-pair target completed.

## Acceptance

Before switching defaults: independent same-model blind V4/V5 evaluation with held-out zh/en/ja/ko posts (>=100 paired posts; stratify by scene and language), measure sendability, grounding, diversity, unsafe copying, hallucinated personal experiences, p50/p95 time to complete valid JSON, input/output tokens and errors. Target >=70% preference among non-ties with ties separately reported, no material latency regression, one provider call, unchanged request/ACK/quota contract. No real-provider calls made by this PR. Staging guarded release requires separate approval; Production untouched.

## Second tranche

Prefer external examples over synthetic only when keywords and scene provide evidence. No runtime external fetching. All records remain experimental editorial candidates; no claim of independent human review or measured improvement. Further expansion requires quality screening, especially modern tech/AI and authentic Japanese/Korean data.

## Conservative post-generation preference
After the existing shared serializer accepts the model output, explicitly opted-in Staging V5 may promote an already-generated non-humor candidate when the original default is an exact stock phrase or a very specific boilerplate pattern. No rewriting, candidate deletion, score change, extra provider request, new response fields, rejection, or replay mutation. V4 and Production remain byte-identical at this seam. This is a heuristic, not an AI detector or a measured quality gain. Quote and skip are unchanged. Run node --test tests/reply-v5-quality.test.js along with the retrieval tests.
