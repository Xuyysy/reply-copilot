# Staging interaction assistant — user-initiated live observation

Open X notifications in the active tab, open the extension side panel and select "读取当前通知" or "开始连续读取". In continuous mode, manually scroll through the page; local reads run only during the explicit 90-second / 60-read session, no automatic scroll, X request, credentials, page-world interception, permanent observer or background task. Stop or close panel to stop. Current document, active tab and visible handle must agree for each batch; navigation or tab change clears the observation. Counts are provisional by handle and visible evidence, not verified numeric user IDs; do not persist or merge these records into the separate offline workspace. Unknown post IDs stay in current observation only. No claim of 7/30/90 days, full notification history or all hidden actors.

Test gate: Chromium synthetic DOM fixtures plus actual old/new X notifications (English/Chinese, aggregates, replies, missing target, account switch); source availability and platform/privacy review are mandatory before enabling outside Staging. No Production packaging changes or additional permissions. Latest separate offline workbench is kept intact.
