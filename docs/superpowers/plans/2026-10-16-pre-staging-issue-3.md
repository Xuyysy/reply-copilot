# Cloudflare 接入前验收计划

基线：草稿 PR #2 的 `codex/v0.4-credits` 分支。只修改本仓库；不碰远端 Cloudflare、生产 D1、main 或 PR 合并。

1. **插件 AI 路径与界面（P0）**：移除普通用户 BYOK 和直连 DeepSeek 的可执行路径、设置与引导；本地开发通过现有 Worker Mock AI。保持旧浏览器存储键原样，不清除用户数据。更新对应路由与界面测试。
2. **构建与权限（P0）**：仅授权本机开发 Worker 或正式构建中明确提供的 HTTPS Worker Origin；正式构建在缺少安全配置时失败，扫描产物中的开发入口、直连地址与敏感标记。测试开发和正式构建。
3. **商业与安全审计（P0/P1）**：检查未付款订单、额度和后台权限；对可确认的缺口做最小修复并加回归测试。核对网站文案、隐私说明与引导。
4. **综合验收**：在隔离的本地 D1 和 Mock AI 上运行单元、类型、构建、端到端及 Chrome 测试；形成《Cloudflare 接入前审计报告》，逐项区分已验证和待云端验证。
5. **交付**：整理审计报告，提交并推送至 PR #2 开发分支。此次不创建或更新 Issue；全过程不部署或迁移远端资源。
