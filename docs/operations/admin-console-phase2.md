# 管理控制台第二阶段

后台：https://staging.x-reply-helper.top/admin/ 。使用原唯一管理员账号，无需重新绑定。

## 日常使用

- **网站内容**：导航稳定ID、中文/英文名称、显示开关、顺序、允许的目标地址；预览后保存。账户/登录入口独立控制，无法通过普通导航改变认证。首页主按钮可覆盖默认按钮，清空后恢复账户状态按钮。
- **网站内容**：主副标题、正文、功能卡片、套餐区、指南、FAQ、页脚、公告与维护提示。纯文本和正常换行，不接受HTML执行。恢复历史会先保存当前版本；默认恢复先修改草稿，保存后生效。
- **账号与支付开关**：修改密码须验证原密码，新密码至少12位、字母/数字/符号中两类。保留当前会话，其他网页及插件会话退出，密码重置记录和敏感操作证明失效。密码不进入审计或重试缓存。
- **账号与支付开关**：购买需要环境许可、数据库运营开关及凭证格式检查同时通过。Staging环境许可为1，以便后台直接控制；发布时数据库purchase_enabled=0，实际购买关闭。环境PAYMENTS_ENABLED=0始终是紧急关闭。Production保持0。关闭购买不阻断已有订单通知/可信状态收敛。
- **福利发放**：选择对象与次数/类型，先预览人数和总额，再确认创建活动，可手动发放下一批，也可明确确认后连续分批发放；可停止并安全续发。每批最多3人，同一活动/用户唯一回执；余额、批次与流水原子一致。失败后用同一活动续发，不另建重复活动。请求结果不明时可重试原操作查看进度，再继续下一批。
- **福利发放**：默认免费额度；未来新注册领取仅允许全部/未付费活动，截止不超过90天，同时最多3个。注册赠送原200次数不变，活动另记流水；注册事务内确定活动，防止并发漏发。结束活动即停止后续批次与未来领取。
- **用户管理**：按邮箱/ID/注册日期/付费与活动筛选，内部备注、选中导出CSV、批量冻结/恢复。CSV防公式注入，不包含密码或Token。最近活动来自会话创建、AI请求或成功支付，不声称追踪所有页面浏览。
- **套餐**：推荐标签、首页突出展示与预览；美元展示、服务费率和最终CNY结算合同保持原样，旧订单不变。
- **订单**：搜索、状态筛选、通知与尝试记录、错误、权益是否到账、选中CSV。只展示已记录的安全字段，不返回签名、收银链接或Secret。

## 明确保留的边界

当前不提供凭截图补发、直接改支付成功、真实平台查单或自动退款按钮。小豆易支付的商户查证与人工补单，需先独立验证其可信查询合同；在此之前通过商户后台核对并保留记录，不能将普通额度调整伪装为支付到账。

本轮不实际创建福利活动或发放额度，不执行改密、付款、退款或真实支付查询。新功能通过本地Mock和API集成验证，管理员真实浏览器操作由本人验收。
