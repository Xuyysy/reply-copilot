# Offline interaction workspace V1
Open ui/index.html from a local static test host or the isolated Staging package. No live acquisition, no verified X identity; manually selected data owner is an offline partition only. Separate database from verified-event repository default. Format: {"format":"xrh-interaction-evidence-v1","ownerUserId":"111","kind":"post","posts":[{"postId":"123","authorUserId":"222","replyToUserId":"111","replyToPostId":"456"}]} . For kind notification, supply payload instead of posts; optional observedAt in epoch milliseconds. These are developer evidence files, not native X export or a supported live capture flow. Import limit 8 MiB / 20k normalized events, 50k records per workspace; batch commits may survive interruption and replay is deduplicated. Real notification structure and identity are still unverified. No account auto-binding, no network capture, no external API. Full CI and manual Staging acceptance required.
