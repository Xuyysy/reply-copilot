# Interface sync engine V1
Transport-independent, no production provider, no network calls. Provider contract: trusted extension code supplies id, identify({signal}) => independently verified stable ownerUserId and opaque sessionId, readPage({ownerUserId,source,cursor,signal}) => HTTP status, owner/source/requestCursor, verified structure, explicit done/nextCursor and terminalEvidence, plus payload (notification) or structured posts. Never derive identity from a requested user ID; never assert structureVerified based on arbitrary JSON. Current contract is a testable integration seam, not proof of X authorization or live compatibility. Use a dedicated fixture DB for tests, never place fixtures in live storage.
Each source/provider/owner checkpoint and events are committed in one IndexedDB transaction. Resume from last committed cursor; explicit refresh restarts from head, deduplicating old events. Cancellation, identity changes, repeated cursors, 401/403/429 and unknown responses halt; no automatic retries. Per run max 30 pages/90 s by default, max 1000 committed pages per job. No claim of full account history. Ranking is read from local records with unknown dates excluded from dated windows. UI wiring and authorized live transport remain pending.
