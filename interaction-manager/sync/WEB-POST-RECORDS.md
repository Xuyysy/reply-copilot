# Structured web post response decoding
Inspired by the MIT-licensed X-Insights parser [src/parse/tweet.ts](https://github.com/arslandevs/X-Insights/blob/bc56bd0d9ad71cb8e1f9de35dfbf9cfcfb5eb595/src/parse/tweet.ts), independently implemented for our strict owner-scoped event model. Explicit bounded web post records are optionally supplied as page.webPosts by a trusted provider, decoded without I/O, and merged with existing normalized post and notification evidence. Unknown or conflicting identities, bare stubs and unproven repost targets are rejected. Reposts count once per actor and target post, and a post-level timestamp can fill a notification aggregate's unknown time. No text-based guessing or implicit attribution to the owner. Existing provider response proof and pagination gates remain. Tests use synthetic records matching the documented shape. This does not implement or enable a web transport or prove live X compatibility.
