# Interaction core v1 — isolated, not wired to Staging UI yet

Owner: interaction line; separate from follow-manager. Stable string X user IDs, explicit confirmed evidence, event-level dedupe and scoring, unknown or conflicting times excluded from dated windows. Unique likes/reposts are observed user-post relations, not counts of repeated actions. Source exhaustion is never complete history. Session tokens fence late writes; trusted caller must identify owner, cancel on account/logout change and not expose session tokens to X page. Extension-origin IndexedDB, no remote calls. IndexedDB source is untested on real Chrome at this stage; no claim of actual live data integration. The existing DOM probe is intentionally separate. No manifest/build/sidepanel/follow-manager changes. Next: actual sanitized data source evidence, trusted identity bridge, native browser DB tests, then Staging integration.
